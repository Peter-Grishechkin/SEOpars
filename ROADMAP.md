## Где проект сейчас

Версия 0.1.0 (MVP) собрана 2026-11-09. Приложение обходит сайт до 5 000 страниц, наполняет таблицы по ходу обхода, находит проблемы, выгружает CSV и продолжает прерванный обход. Есть CLI `seopars-cli`.

Версия 0.2.0 выпущена 2026-11-12 — первый релиз на GitHub с готовой сборкой (zip, arm64, подпись ad-hoc). К MVP добавлены задачи из групп 1–3 со статусом «готово» ниже: canonical, hreflang, alt, H1 и H2, правило robots.txt, свои зоны ссылок, перелинковка. Остальные задачи групп 1–3 в релиз не вошли, прогона на реальных сайтах до релиза не было.

- **Проверено:** 40 тестов в 9 наборах прошли (`./scripts/test.sh`, 2026-11-12); обход локальной фикстуры; нагрузка 5 000 страниц на фикстуре (2026-11-09, замеры в `README.md`).
- **Не проверено:** критерии «Готово, когда» из спецификации на реальных сайтах (прогон делает Пётр); открытие CSV с кириллицей в Excel и Numbers; VoiceOver.

Версия 0.3.0 выпущена 2026-11-12: № 103, 104, 112, 117 — семь новых проверок (meta refresh, Content-Type, два про sitemap, три про разметку `<head>` и `<body>`) и текст «как исправить» у всех 65 проверок. Обход меняется: ответы `text/plain` скачиваются, чтобы найти в них HTML. Обходы из 0.2.0 открываются. Проверено: 50 тестов в 9 наборах, обход фикстуры, окно приложения в фоне; на реальных сайтах — нет.

## Не решено

В разборе Screaming Frog, но в задачи не вошло: несколько H2 на странице, `<head>` не первым элементом, вес картинки больше 100 КБ, вторая ось «приоритет» у проблем, пакетная выгрузка.

Известные ограничения версии 0.3 из `README.md`, решения по ним нет:
- сжатые sitemap `.gz` не читаются;
- во вкладке «Ссылки» видны первые 5 000 строк под фильтр, CSV выгружает все;
- README и AGENTS.md пишут про сборку с SDK macOS 26.5 через `scripts/sdk.sh`. На этом Mac стоит Xcode (замечено 2026-11-11): `xcode-select -p` указывает на `Xcode.app`, `xcrun --show-sdk-version` даёт 27.2, `sdk.sh` ничего не подменяет (проверено 2026-11-12). Проверить сборку и тесты с Xcode и поправить README и AGENTS.md — карточка № 230 во «Входящих».
