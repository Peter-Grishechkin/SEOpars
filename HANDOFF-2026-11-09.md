# SEOpars: спецификация интерфейса для разработки

Дата: 2026-11-09. Версия приложения 0.1.0.
Источники: макет в локальном Penpot (файл «SEOpars», страницы «Основы», «Компоненты», «Паттерны»), токены и правила — `DESIGN-SYSTEM-2026-11-09.md`, поведение — код в `Sources/SEOpars`.

Обозначения в документе:
- **[код]** — так уже работает в приложении, сверено по исходникам 2026-11-09;
- **[макет]** — задано в Penpot;
- **[нужно]** — требование, которого в коде пока нет;
- **[открыто]** — не решено, решение за Петром.

## 1. Обзор

SEOpars — нативное macOS-приложение (SwiftUI, macOS 15+), которое обходит сайт и показывает SEO-данные в таблицах прямо во время обхода. Пользователь — SEO-специалист: запускает обход, ждёт, разбирает проблемы и выгружает CSV. Окно одно, работа идёт за большим монитором, мышью и клавиатурой.

Главный принцип: **интерфейс системный**. Цвета, шрифты, кнопки, таблицы и разделители — стандартные элементы SwiftUI/AppKit. Поэтому тёмная тема, акцентный цвет, увеличенный текст и «уменьшение прозрачности» работают без дополнительного кода. Penpot фиксирует, какие системные роли где используются, а не задаёт новые цвета.

## 2. Как переводить токены в код

Главное правило: **hex-значения из Penpot в код не переносить.** Это снимок системных цветов macOS 27 на 2026-11-09. В коде нужна системная роль, которая сама переключает тему и следует версии macOS.

| Токен | В SwiftUI | Значение Light / Dark (для сверки) | Где |
| --- | --- | --- | --- |
| `color.text.primary` | `.primary` | rgba(0,0,0,.847) / rgba(255,255,255,.847) | основной текст |
| `color.text.secondary`, `color.status.muted` | `.secondary` | rgba(0,0,0,.498) / rgba(255,255,255,.549) | подписи, нули, пустые состояния, robots.txt |
| `color.text.tertiary` | `.tertiary` | rgba(0,0,0,.259) / rgba(255,255,255,.247) | неактивное |
| `color.fill.badge` | `.quaternary` (как фон) | rgba(0,0,0,.098) / rgba(255,255,255,.098) | чип анкора |
| `color.fill.tile` | `.quaternary.opacity(0.5)` | ≈ .049 | плитка обзора |
| `color.bg.*`, `color.border.separator`, `color.bg.selection` | не задавать: даёт `List`, `Table`, `Divider` | см. DESIGN-SYSTEM | фон, разделители, выделение |
| `color.accent` | `.accentColor` / `.keyboardShortcut(.defaultAction)` | #007AFF | основная кнопка |
| `color.status.ok` | `.green` | #34C759 / #30D158 | 2xx: счётчик и ячейки «Код», «Код цели», «Код конечного» = 200 |
| `color.status.redirect`, `color.severity.warning` | `.orange` | #FF8D28 / #FF9230 | 3xx, ссылка на редирект, предупреждение |
| `color.status.error`, `color.severity.error` | `.red` | #FF383C / #FF4245 | 4xx, 5xx, ошибка соединения, битая ссылка |
| `color.severity.notice` | `.blue` | #0088FF / #0091FF | замечание |
| `color.heading.h1…h6` | `.red`, `.orange`, `.green`, `.blue`, `.purple` (H5–H6) | — | бейдж уровня |

| Токен типографики | В SwiftUI | Размер / строка |
| --- | --- | --- |
| `typography.title2-bold` | `.title2.bold()` | 17 / 22 |
| `typography.headline` | `.headline` | 13 / 16, жирный |
| `typography.body` | `.body` (по умолчанию) | 13 / 16 |
| `typography.body-medium` | `.fontWeight(.medium)` | 13 / 16 |
| `typography.callout` | `.callout` | 12 / 15 |
| `typography.caption` | `.caption` | 10 / 13 |
| `typography.caption-mono-bold` | `.caption.monospaced().bold()` | 10 / 13 |
| `typography.code` | `NSFont.monospacedSystemFont(ofSize: 11)` | 11 / 14 |
| `typography.callout-mono` | `.system(.callout, design: .monospaced)` | 12 / 15 |

В макете Inter и JetBrains Mono заменяют SF Pro и SF Mono, которых нет в Penpot. В коде шрифт не задавать: нужен системный.

Все числа в счётчиках, плитках и столбцах таблиц — `.monospacedDigit()`, чтобы цифры не прыгали при обновлении во время обхода.

**Отступы и скругления** [код] [макет]: `spacing.panel` 12 (`.padding(12)` у панелей), `spacing.overview` 16, `spacing.sheet` 20, `spacing.empty-state` 32, `spacing.toolbar-gap` 10, `spacing.stats-gap` 16, `spacing.stat-pair-gap` 4, `spacing.tile-gap` 12, `spacing.section-gap` 20, `spacing.heading-indent` 18. Скругления: `radius.badge` 4, `radius.tile` 8. Для новых отступов брать значения из шкалы `spacing.2 … 32`, не придумывать свои.

## 4. Экраны

### 4.1. Новый обход (`NewCrawlView`)

- Панель сверху, `.padding(12)`, промежутки 10: сегменты «Паук / Список URL», поле адреса (`https://example.ru/`) или кнопка «Список URL (N)…», кнопки «Настройки» и «Старт».
- «Старт» — основная кнопка (`.defaultAction`, Return), Return в поле адреса тоже запускает обход.
- Ниже, `.padding(32)`, ширина 320–640: заголовок «Новый обход» (`title2-bold`), сводка настроек (`.secondary`), где лежат файлы обходов (`callout`, `.secondary`).
- В Penpot этот экран не рисуется: он собран из системных контролов, описания хватает (решение 2026-11-10, §10).

### 4.2. Окно обхода (`CrawlView`) [макет: «Паттерны» → «Окно: обзор обхода»]

Сверху вниз: верхняя панель → строка счётчиков → разделитель → вкладки → содержимое вкладки и инспектор.

**Верхняя панель** (`CrawlTopBar`). Компоненты: «Кнопка».

| Элемент | Правило |
| --- | --- |
| Значок режима | `globe` для паука, `list.bullet` для списка, `.secondary` |
| Адрес | `headline`, одна строка, обрезка посередине, текст выделяется; для списка — «Список: N URL» |
| Пауза, Стоп | видны, пока обход идёт; неактивны в состоянии «Останавливаю» |
| Продолжить | вместо них, если обход можно продолжить |
| Пороги | открывает лист порогов; подсказка «Пороги проверок и настройки этого обхода» |
| Экспорт | меню: «Всё в папку (CSV)…», затем по таблицам |
| Инспектор | переключатель (`.toggleStyle(.button)`), подсказка «Показать или скрыть инспектор страницы» |

**Строка счётчиков** (`StatsBar`). Компонент «Счётчик», варианты Обычный / Успех / Редирект / Ошибка / Ноль.

- Слева статус обхода (`callout`, обычное начертание, как в макете) с маленьким `ProgressView`, пока обход идёт.
- Счётчики: Обойдено, В очереди, 2xx, 3xx, 4xx, 5xx, Ошибки, robots. Подпись `.secondary`, значение цветное, но только если оно больше нуля; ноль — `.secondary`.
- Скорость «4.2 URL/с» — только во время обхода (формат `%.1f`, разделитель — точка).
- Справа, пока анализ не окончательный: значок `hourglass` и «Обход не завершён: дубли, сироты и глубина — промежуточные» (`caption`, `.secondary`). Если текст не помещается, остаётся только значок (`ViewThatFits`), текст — в подсказке `.help` и в `accessibilityLabel` [код, 2026-11-10]. Пометка видна, пока обход активен: «Загружаю robots.txt и sitemap», «Идёт обход», «Останавливаю». На «Паузе» и «Прерван» анализ пересчитывается как окончательный и пометки нет (SPEC, п. 1.6).
- Счётчики, статус и скорость не сжимаются и не переносятся (`.fixedSize()`). Проверено 2026-11-10 на окне 1100 × 752 с боковой панелью по умолчанию: всё в одну строку, пометка свёрнута в значок; на окне 1391 — пометка полным текстом.

**Вкладки.** Компонент «Сегмент». Подписи: «Обзор», «Страницы · N», «Мета-теги», «Заголовки», «Ссылки», «Редиректы · N» (если есть), «Проблемы · N» (если есть). Выбранная вкладка запоминается (`@SceneStorage("crawlTab")`, по умолчанию «Страницы»).

### 4.3. Обзор (`OverviewView`) [макет: «Паттерны» → «Обзор обхода»]

- Прокрутка, `.padding(16)`, между блоками 20.
- Сетка плиток: `LazyVGrid`, адаптивные столбцы от 150, промежуток 12. Компонент «Плитка». Порядок и цвета плиток — как в коде: 3xx оранжевая, 4xx, 5xx и «Нет соединения» красные, остальные обычные. Значение «0» — `.secondary` при любом варианте.
- «Главные проблемы»: заголовок `headline` и кнопка «Все проблемы» (переход на вкладку «Проблемы»). До 12 строк, сначала ошибки, потом предупреждения и замечания, внутри группы — по убыванию числа. Компонент «Строка проблемы»: промежуток 8, отступ сверху и снизу 4.
- «Журнал» (если есть сообщения) и раскрывающийся блок «robots.txt» моноширинным `callout`.

### 4.4. Таблицы: Страницы, Мета-теги, Заголовки, Ссылки, Редиректы

Общая панель над таблицей: фильтр (`Picker`, ширина 300), поиск (до 360), справа «N из M» (`.secondary`, моноширинные цифры) и кнопка «CSV» с подсказкой.

| Таблица | Столбцы [код] |
| --- | --- |
| Страницы | URL, Код, Индексируемость, Правило robots.txt (с 2026-11-11, № 105), Тип, Ответ мс, КБ, Глубина, Входящие, Уник. вход., Исх. внутр., Исх. внеш., Слов, Sitemap, Проблем |
| Мета-теги | URL, Код, Title, Длина, Description, Длина, Canonical, Canonical URL, Meta robots, Индексируемость |
| Заголовки | URL, H1, Число H1, H2…H6, Проблемы, Title |
| Ссылки | Источник, Цель, Анкор, Код цели, Тип, rel, Зона, Где |
| Редиректы | URL, Код, Куда, Конечный URL, Код конечного, Шагов, Петля |

Цвет в ячейках [код] — компоненты «Код ответа» и правила ниже:
- код ответа: 2xx `.green`, 3xx `.orange`, 4xx и выше `.red`, ошибка соединения `.red`, «robots.txt» `.secondary`;
- длина title и description [код, 2026-11-10] — отклонение видно не только цветом: короче порога — «24 ↓» `.orange`, длиннее — «72 ↑» `.orange`, в норме — число `.primary`, пусто — «нет» `.red`, страница не HTML с кодом 200 — «—» `.secondary` (раньше там стоял красный «—»). VoiceOver читает «72, длиннее порога». Логика — `LengthVerdict` в `SEOparsCore/Models.swift`, столбцы «Длина» — мин. 48, по умолчанию 58;
- индексируемость: «нет» — `.orange`;
- число H1: не равно 1 — `.red`; проблемы заголовков — `.orange`;
- ссылка (код цели): 2xx — `.green`, битая — `.red`, на редирект — `.orange`, не проверялась — `.primary`;
- редирект: код всегда `.orange`, конечный код 200 — `.green`, иначе `.red`, шагов больше 1 — `.orange`, петля — `.red`.

Строки с длинным текстом (URL, title, description, анкор) обрезаются, полный текст — во всплывающей подсказке (`.help`).

### 4.5. Проблемы (`IssuesView`)

- Слева список по группам: Title, Description, H1, Заголовки, Ответы сервера, Индексация, Разметка HTML, Hreflang, Ссылки, Контент (обновлено 2026-11-12). В строке: значок важности, название (до 2 строк), `hourglass`, если число промежуточное, и число справа.
- Пустые группы не показываются.
- Справа детали: название (`headline`), кнопка CSV, пояснение (`callout`, `.secondary`; если у проблемы его нет — строки нет), строка «Как исправить: …» (`callout`, начало жирным, текст выделяется; с 2026-11-12), таблица URL с одним столбцом подробностей под тип проблемы. В CSV по проблеме — колонка «Как исправить». Ничего не выбрано — «Выберите проблему слева».

### 4.6. Инспектор страницы

- Сегменты: «Сводка», «Заголовки», «Входящие · N», «Исходящие · N», «HTTP», «Код». Выбранная вкладка запоминается.
- Рядом адрес страницы (`.secondary`, обрезка посередине) и две кнопки-иконки: `safari` «Открыть в браузере», `doc.on.doc` «Скопировать URL».
- «Заголовки» [макет: «Паттерны» → «Дерево заголовков»]: столбец с промежутком 6 и отступом 12 (прокрутка, не `List`), компонент «Строка дерева заголовков», сдвиг 18 на каждый уровень ниже H1, пустой заголовок — «(пустой заголовок)» `.red`, пропуск уровня — «пропуск уровня: H2 → H4» `caption` `.orange`.
- «Входящие»: над таблицей анкоры — до 30 чипов (компонент «Чип анкора»), подсказка на чипе «анкор: число».
- «Код»: моноширинный 11, пока грузится — `ProgressView`.

### 4.7. Боковая панель «Обходы»

Компонент «Элемент обхода», варианты Обычный / Выбран. Первая строка — адрес, одна строка с обрезкой посередине. Вторая (`caption`, `.secondary`): дата и время, «N стр.», статус, если обход не завершён («Пауза», «Прерван»). Счётчик страниц у текущего обхода обновляется вживую.

### 4.8. Листы: «Настройки», «Пороги», «Список URL»

В Penpot не рисуются (решение 2026-11-10, §10): всё из системных контролов в `Form(.grouped)`, макет дал бы только приближение AppKit. Состав — по коду `SettingsView.swift` и `ContentView.swift`.

- **«Настройки» нового обхода** (`SettingsView`, 620 × 680). Секции: «Область» (Границы — `Picker`; Лимит URL 10–50 000 шаг 500; Глубина 0–50, 0 — «без ограничения»), «Скорость» (Потоков 1–10; Пауза 0–10 000 мс шаг 100; Тайм-аут 5–120 с шаг 5; пояснение про Crawl-delay), «Робот» (User-Agent — `Picker`, для «своего» — поле строки; «Учитывать robots.txt»; пояснение про Clean-param), «Sitemap» (загружать, адрес, обходить адреса; поля неактивны, если не загружать), «Фильтры URL» (три поля `LinesEditor` высотой 54: Исключить, Обходить только, Игнорировать параметры), «Зоны ссылок: свои правила раньше эвристики» (с 2026-11-11, № 115: строки «зона ← CSS-селектор» с кнопкой удаления, «Добавить правило», пояснение, раскрывающийся блок «Проверить на вставленном HTML» — поле HTML и список ссылок с зоной, а если эвристика решила бы иначе — «(эвристика: …)»), «Пороги проверок (ориентиры, не нормы поисковиков)» (с 2026-11-11 добавлены H1 и H2 до 70, alt до 100). Внизу «Сбросить настройки» и «Готово» (Return). Для запущенного обхода поля неактивны.
- **«Пороги» обхода** (`ThresholdsSheet`, 560 × 620). Секция порогов (как выше) и «Настройки этого обхода» — только чтение (`LabeledContent`): границы, лимит, глубина, потоки / пауза, робот, robots.txt, sitemap, фильтры, если заданы; пояснение «начните новый обход (⌘N)». Внизу «Отмена» и «Применить» (Return).
- **«Список URL»** (`URLListSheet`, мин. 560 × 320 у поля). Заголовок `headline`, пояснение `callout` `.secondary`, моноширинный `TextEditor` с рамкой `.secondary` 30 %, внизу «Загрузить из .txt…», «N URL» `.secondary`, «Отмена», «Готово» (Return).
- Вкладки-таблицы описаны в §4.4. Если понадобится новый вариант ячейки, в Penpot добавляется только он, вкладки целиком не перерисовываются.

## 6. Состояния и взаимодействия

Наведение в macOS-приложении — это системная подсветка контролов и подсказки `.help`. Своих эффектов наведения нет и не нужно.

## 7. Граничные случаи

- **Нет данных.** Инспектор без выбора — «Выберите страницу в таблице». Проблем нет — «Пока нет данных» до первых страниц, затем «Проблем не найдено». Заголовков ответа нет — «Заголовков ответа нет». Пустое значение в сводке — «—».
- **Длинный текст.** URL и адреса — одна строка с обрезкой посередине (видны домен и конец пути). Ячейки таблиц обрезаются, полный текст в подсказке. Названия проблем — до 2 строк.
- **Кириллица и `.рф`.** Показывать читаемый вариант (`URLNormalizer.display`), в CSV и при копировании «закодированного» — percent-encoding. Русские подписи длиннее английских: не задавать фиксированную ширину кнопкам и сегментам.
- **Большие объёмы.** Вкладка «Ссылки» показывает первые 5 000 строк под текущий фильтр, над таблицей `caption` оранжевым: «В таблице первые N из M. Уточните фильтр или поиск, все строки — в CSV.»; CSV выгружает все строки. При пересчёте ссылок — маленький `ProgressView` в панели фильтров.
- **Промежуточные числа.** Дубли, сироты и глубина до конца обхода — промежуточные, это помечено в строке счётчиков и в списке проблем.
- **Исходный код.** Сохраняется только для HTML с кодом 2xx, иначе текст «Исходный код сохраняется только для HTML-страниц с кодом 2xx.».
- **Медленный сайт.** Таблицы и счётчики наполняются по мере обхода; долгий ответ (порог 1 500 мс по умолчанию) — проблема в группе «Ответы сервера».

**Что нужно сделать [нужно]** — пункты 1–4 и 6 в Trello № 125:
1. **Подписи для VoiceOver у кнопок-иконок.** В коде нет ни одного `accessibilityLabel` (проверено поиском 2026-11-09). 4. **Плитка и счётчик.** Объединить подпись и значение в один элемент (`.accessibilityElement(children: .combine)`), чтобы VoiceOver читал «Ошибки 4xx, 17», а не два элемента подряд.
5. **Контраст цветного текста в светлой теме ниже 4,5:1** (WCAG AA): оранжевый 2,31, зелёный 2,22, синий 3,52, красный 3,57, фиолетовый 4,17. В тёмной теме все проходят. Решение вынесено в Trello № 122.
